# CRM المحترف: الفرونت

## التشغيل

```powershell
npm install
npm run dev
```

عنوان الـ API يُضبط عبر `VITE_API_URL` ويجب أن يتضمن `/api`. إعدادات `.env.local` شخصية ولا تُرفع إلى Git.

في وضع التطوير، `VITE_USE_MOCKS=true` يشغّل MSW لمسارات تسجيل الدخول والمستخدمين. استخدم `VITE_USE_MOCKS=false` لاختبار الاتصال بالخادم الفعلي. أسماء الدخول الوهمية في وضع MSW هي أسماء الأدوار الموجودة في `src/permissions/roles.ts`، وأي كلمة مرور غير فارغة مقبولة.

## تكامل الواجهات مع الباك إند الموجود في المستودع

- تسجيل الدخول: `POST /auth/login` مع `accountName` و`password`. الخادم الحالي يعيد `refreshToken: null` ولا يوفّر refresh/logout؛ تسجيل الخروج يمسح الجلسة محلياً.
- المستخدمون: `GET /users`, `GET /users/{id}`, و`PUT /users/{id}`. معاملات البحث والترقيم PascalCase، وأجسام التعديل camelCase. يوجد `POST /users` لكن `AddUserCommandHandler` فارغ، لذا واجهة الإضافة متوقفة ولا ترسل الطلب.
- جهات الاتصال: `GET /contacts` مع فلاتر الاسم والحملة والمسار والحالة والوسوم ورقم الصفحة. تُرسل `TagIds` كمفاتيح متكررة، وتطابق الاستجابة `{ items, page }`.
- القوائم: `GET /lookups` يطلب `Departments`, `Roles`, `Tracks`, و`LeadStatuses` صراحةً بصيغة `Include` المتكرر؛ نتيجة الطلب مشتركة ومخزّنة عبر TanStack Query.
- تُرفق ترويسة `Authorization: Bearer` بطلبات API عند توفر رمز دخول.

## فجوات عقد API / الخادم

- لا تحتوي نسخة الخادم الموجودة في مساحة العمل على endpoints للحملات، تفاصيل/استيراد جهات الاتصال، أو تقارير الحملات؛ لذلك مسارات الحملات تعرض عدم التوفر ولا تطلق طلبات لها.
- شاشات التوجيه الأكاديمي، المشاكل، الإشعارات، وتغيير كلمة المرور لا تملك عمليات مطابقة في عقد API الحالي.
- القوائم المتاحة من الخادم هي الأقسام والأدوار والمسارات وحالات العملاء فقط؛ لا تتضمن Tags أو بيانات الحملات. لذلك لا تظهر خيارات وسم فعلية في فلتر جهات الاتصال.
- مسار `GET /contacts` في OpenAPI موثق كمسار محمي، لكن `ContactsController` الحالي لا يحمل `[Authorize]`. يرفق عميل الواجهة Bearer token عند توفره، لكن فرض المصادقة يحتاج تعديل الخادم.
- عند اختبار API الفعلي، استخدم `VITE_USE_MOCKS=false`. وضع MSW يدعم تسجيل الدخول والمستخدمين محلياً فقط؛ لا يوجد mock لجهات الاتصال.
- يوجد مسار `POST /users` في `UsersController`، لكن معالج الأمر `AddUserCommandHandler` في نسخة الخادم الموجودة في مساحة العمل فارغ حالياً. لن ترسل الواجهة طلب الإضافة حتى يكتمل المعالج.

## أوامر مفيدة

- `npm run lint` : فحص الكود وقواعد الحدود بين المجلدات.
- `npm run typecheck` : فحص TypeScript.
- `npm run build` : بناء نسخة نهائية.
- `npm run format` : تنسيق ملفات `src`.

اقرأ `docs/conventions.md` قبل إضافة ميزات جديدة.
